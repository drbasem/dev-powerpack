# dev-powerpack

**مهارة واحدة تجعل وكيل البرمجة الذكي يعمل بأسلوب مهندس برمجيات خبير، وتمنحه أربع أدوات قوية.**

[English](README.md)

خمسة مشاريع مفتوحة المصدر، كلٌّ منها يحل جزءًا من مشكلة البرمجة بالذكاء الاصطناعي. لكن عند تثبيتها منفصلة لا أحد يخبر الوكيل *متى* يستخدم كل أداة. تجمع `dev-powerpack` هذه المشاريع في مهارة واحدة بدورة عمل واحدة، مع موجِّه يستدعي الأداة المناسبة في اللحظة المناسبة.

## المكوّنات الخمسة

| المشروع | المشكلة التي يحلها | دوره في المهارة |
|---|---|---|
| [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) | الوكيل يتخطى التخطيط، ويكتب تعديلات ضخمة بلا اختبارات، ويراجع بسطحية | العمود الفقري: مواصفات ← خطة ← شرائح صغيرة ← اختبار أولًا ← مراجعة على خمسة محاور ← إطلاق |
| [upstash/context7](https://github.com/upstash/context7) | النماذج تكتب كودًا من بيانات تدريب قديمة وتخترع دوالًا غير موجودة | قبل استخدام أي مكتبة: جلب التوثيق الحالي الخاص بالإصدار والاستشهاد به |
| [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) | الوكيل يستهلك السياق في البحث ملفًا بعد ملف | تحويل المشروع إلى خريطة معرفية محلية والاستعلام عنها بدل قراءة كل شيء |
| [21st-dev/magic-mcp](https://github.com/21st-dev/magic-mcp) | واجهات الذكاء الاصطناعي تبدو متشابهة وعامة | البدء من مكوّن واجهة جاهز ومُتقن ثم تكييفه مع تصميم المشروع |
| [usestrix/strix](https://github.com/usestrix/strix) | أدوات الفحص التقليدية مليئة بالإنذارات الكاذبة | اختبار اختراق آلي لتطبيقك *أنت* مع إثبات عملي لكل ثغرة، ثم إصلاح وإعادة فحص |

كل أداة **اختيارية**؛ إن لم تكن مثبتة تلجأ المهارة لبديل (التوثيق الرسمي، البحث العادي، كتابة الواجهة يدويًا، قائمة فحص أمني يدوية) ولا تتوقف.

## ما الذي يتغير في سلوك الوكيل؟

- يذكر نوع المشروع وإصداراته وافتراضاته قبل البدء.
- يكتب مواصفات قصيرة للمهام غير البسيطة، ثم يقسمها لمهام صغيرة قابلة للتحقق.
- يراجع التوثيق الحالي قبل استخدام أي واجهة برمجية.
- يستعلم عن خريطة الكود قبل التخطيط أو تتبع الأخطاء في المشاريع الكبيرة.
- يبني الواجهات من مكوّنات حقيقية لا من صفحة فارغة.
- يكتب الاختبار الفاشل أولًا، ولا يُضعف اختبارًا ليجعله ينجح.
- يراجع على خمسة محاور: الصحة، الوضوح، البنية، الأمان، الأداء.
- يُجري فحصًا أمنيًا قبل الإطلاق (على الأهداف المملوكة لك فقط).
